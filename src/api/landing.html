    For developers

    Everything above runs on a free public API. No key required. 

    curl "__BASE__/v1/puzzles/random?rating=1500&themes=fork"
    • Full API reference and OpenAPI schema.
    • llms.txt, and an MCP server at __BASE__/mcp for agents.
    • 30 requests a minute per IP; a key raises that.
    • Source on GitHub, MIT licensed.
