    What does this notation mean?

    Each move names the piece and where it goes. Letters come from the English names:

    • K king · Q queen · R rook · B bishop · N knight
    • No letter means a pawn, as in e4.
    • x capture · + check · # checkmate · O-O castling

    So Bxa3+ reads: the bishop captures on a3, giving check.
